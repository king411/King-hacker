**Ethical hacking & cybersecurity tips and tricks** by **King Computer Services**, Delhi.

Learn how attackers think so you can protect your own PCs, phones, networks and accounts. Everything here is for **learning and defence only**.

---

## 🚀 Getting started

1. Set up a safe lab using **VirtualBox** or **VMware** with **Kali Linux**.
2. Practise only on your own machines or on legal platforms like **TryHackMe** and **Hack The Box**.
3. Learn networking basics (IP, ports, DNS, HTTP) before touching any tool.
4. Take notes, and share what you learn to help others stay safe.
